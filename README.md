## Running the code

Install Python 3, clone this repository, and run a solution from the repository root:

```bash
git clone https://github.com/Lance-Adhikari/data-structures-and-algorithms.git
cd data-structures-and-algorithms
python "Practice Notes/GCD_1.py"
python "Practice Notes/GCD_2.py"
```

Enter one integer at each prompt. These scripts use only Python's standard features; no extra packages are needed.

These are learning exercises, with the original solution code preserved. The notes explain each approach and record known limitations, so an entry may represent work in progress. Course materials and assignment statements are not included.
